# 🛒 Toko Online

Website toko online berbasis PHP Native dan MySQL/MariaDB.

Project ini dibuat sebagai project pembelajaran dan pengembangan sistem e-commerce sederhana, dengan fitur toko untuk pelanggan serta halaman administrasi untuk mengelola produk dan pesanan.

## 📌 Status Project

🚧 **Beta Version — v0.1.0**

Project sudah dapat dijalankan dan alur utama toko online sudah berfungsi, tetapi masih dalam tahap pengembangan.

## ✨ Fitur

### 👤 Pelanggan

- Registrasi akun
- Login dan logout
- Melihat daftar produk
- Melihat detail produk
- Menambahkan produk ke keranjang
- Mengubah isi keranjang
- Checkout
- Melihat pesanan
- Profil pelanggan
- Sistem poin

### 🔐 Admin

- Login admin
- Dashboard admin
- Menambah produk
- Mengedit produk
- Menghapus produk
- Upload gambar produk
- Melihat daftar pesanan
- Melihat detail pesanan
- Mengubah status pesanan

## 🛠️ Teknologi

- PHP Native
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- PDO
- XAMPP
